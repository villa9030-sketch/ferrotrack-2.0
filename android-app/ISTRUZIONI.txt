FerroTrack LS — App Android per tablet officina
================================================

COSA FA:
- Una sola app per tutti i tablet: al primo avvio chiede l'indirizzo del server
  (di solito http://192.168.1.10:5000) e che tablet e': "Tablet ore" o
  "Tablet officina". Restano salvati.
- Schermo intero, schermo sempre acceso, Indietro non fa uscire dall'app
- Se il server non risponde mostra un avviso e riprova da solo ogni 10 secondi
- Per cambiare server o postazione: 5 tocchi rapidi nell'angolo in alto a
  sinistra (oppure "Impostazioni" nell'avviso di server non raggiungibile)
- Prima volta su ogni tablet: la pagina chiede di registrare il tablet col PIN
  dell'amministratore (come per le postazioni PC)

COME COMPILARE:

1. Installa Android Studio: https://developer.android.com/studio
   (download ~1 GB, installazione ~10 min)

2. Apri Android Studio → "Open" → seleziona la cartella "android-app"

3. Aspetta che Gradle scarichi le dipendenze (prima volta: 2-3 min)

4. Menù: Build → Build Bundle(s) / APK(s) → Build APK(s)

5. L'APK si trova in: android-app/app/build/outputs/apk/debug/app-debug.apk

COME INSTALLARE SUL TABLET:

1. Copia app-debug.apk sul tablet (via USB, email, o Google Drive)
2. Apri il file sul tablet
3. Se dice "origini sconosciute", vai in Impostazioni → Sicurezza → abilita
4. Installa
5. L'app appare come "FerroTrack LS" con l'icona verde

CAMBIARE IP SERVER:
Non serve ricompilare: 5 tocchi in alto a sinistra -> Impostazioni.
